# Light Space

Десктопное приложение (WPF, .NET 10) в трее, которое управляет подсветкой всех лент и клавиатур и продолжает работать при свёрнутом окне.

## Проекты

| Проект | Что в нём |
| --- | --- |
| `LightSpace.Core` | Цвета, геометрия сцены, модели конфигурации |
| `LightSpace.Devices` | Драйверы устройств |
| `LightSpace.Engine` | Цикл кадров, рендер содержимого, вывод на устройства, источники (экран, звук, игры) |
| `LightSpace.App` | Окно, трей, страницы и компоненты дизайн-системы |
| `LightSpace.Tests` | Тесты миграций конфига, профилей и байтов команд устройств (`dotnet test`) |

## Что умеет сейчас

- **Окно** на тёмном стекле (Acrylic или Mica, пресеты и ползунки тонировки); содержимое — скруглённая карточка с отступом от краёв окна. Левое меню сворачивается до значков: «Устройства», «Мониторы», «Профили», список найденных устройств и внизу «Настройки».
- **Устройства**: поиск по Bluetooth, Wi-Fi и USB (ELK/MELK и Triones, Magic Home, Govee, Tuya, WLED, OpenRGB, Arduino, Robobloq, Royal Kludge S98), локальный ключ Tuya, возможности устройства и диагностика вывода (отправлено, пропущено кадров, последняя ошибка, время расчёта кадра). В списке у устройства значок с цветной точкой состояния связи; «Возможности» и «Диагностика» свёрнуты, пока их не откроют, а «Забыть устройство» — внизу, красной кнопкой, с подтверждением.
- **Устройства в левом меню**: у каждого свой значок (выбирается щелчком по значку на странице устройства) с точкой живого цвета, который сейчас уходит на устройство; при проблеме со связью точка жёлтая или красная, ненайденное устройство приглушено.
- **Страница устройства** (пункт устройства в меню): в шапке — значок, название (кнопка-карандаш переименовывает; пустое название возвращает имя от драйвера), тип и состояние связи, справа яркость устройства, под ними полоса живых цветов. У неподключённого устройства вместо настроек — подсказка и кнопка «Найти устройства». Своё содержимое и яркость у каждого устройства. Типы — «Эффект», «Музыка» (спектр, ритм, пульс от звука компьютера) и у ленты, повешенной за монитор, «Экран» (лента повторяет цвета краёв монитора; насыщенность, яркость, сглаживание). Монитор ленты выбирается здесь же. Во вкладке «Эффект» галерея занимает основную часть: сверху плитки встроенных эффектов контроллера (только у устройств, где они есть; картинка плитки подобрана по названию, варианты одного эффекта — одна плитка), ниже эффекты приложения. Выделена плитка того, что играет; щелчок по любой плитке сразу её включает. Настройки — в выезжающей панели справа: у эффекта приложения его параметры, у встроенного — пресеты (варианты эффекта), скорость (шаг 1 %; 100 % — самая высокая скорость, на которой контроллер ещё не останавливает эффекты) и цвет. Просмотр другого типа не останавливает то, что играет, пока не нажата «Включить». У неподключённого устройства настроек нет — только подсказка найти его.
- **Мониторы**: лента за монитором, ориентация монитора, раскладка ленты по сторонам, начало и направление.
- **Настройки** (карточки в две колонки): слева общий выключатель подсветки и общая яркость, автозапуск с Windows (старт сразу в трей) и версия; справа внешний вид и стекло — готовые варианты, а ползунки в свёрнутой «Тонкой настройке». Найденное обновление — плашкой с кнопкой «Скачать» наверху страницы и акцентной точкой у «Настроек» в левом меню.
- **Журнал устройств** (скрытый раздел: 7 щелчков по заголовку «Настройки»): поиск и подключение по Bluetooth, каждая команда на устройство с байтами и ответом, смена эффектов и ошибки. Кнопки «Скопировать», «Открыть папку» (`%AppData%\LightSpace\log.txt`), «Очистить». По умолчанию выключен.
- **Bluetooth-ленты** (ELK/MELK, Triones) после подключения сначала получают команду включения — на случай, если их выключили с пульта или телефона.
- **Сон компьютера**: перед сном свет на всех устройствах гаснет, после пробуждения возвращается (выключатель подсветки в настройках при этом не меняется).
- **Переподключение**: пропавшие устройства ищутся сами — через 15 с, потом всё реже, до раза в 5 минут; после пробуждения компьютера сразу. Устройство, до которого команды не доходят дольше 30 с, переподключается заново. Подсказка значка в трее показывает, со сколькими устройствами нет связи; необработанные ошибки приложения пишутся в `%AppData%\LightSpace\log.txt`.
- **Профили** (свой раздел в левом меню): текущую подсветку (что играет на каждом устройстве и с какой яркостью) можно сохранить профилем и потом применить одним щелчком. У профиля видно, что он включает на каждом устройстве; там же его можно переименовать, поменять яркость устройства, убрать устройство из профиля, перезаписать текущей подсветкой или удалить. Профиль, который сейчас играет, отмечен галочкой — и здесь, и в меню трея (там же подсказка, что он включает). Устройства, которых в профиле нет, продолжают играть своё. Общая яркость, которая приглушает все устройства разом, — в «Настройках».
- **Трей**: левый клик открывает окно, правый — своё меню: сверху сколько устройств на связи и со сколькими её нет, ниже выключить/включить подсветку, общая яркость, профили, «Открыть Light Space», «Выход». Свернуть — окно прячется в трей, подсветка работает; закрыть — приложение завершается.
- Настройки — в `%AppData%\LightSpace\config.json` (формат версии 4).

Пока не показываются: страница «Сцена» (режимы «Вся сцена» и «Группы», расстановка, слои) и типы «Сцена», «Игра» — код для них есть, но в интерфейсе они выключены, а устройства, которые их играли, при запуске переходят на обычный эффект (как и «Экран» у ленты, которую сняли с монитора).

## Запуск

```
cd LightSpace
dotnet run --project LightSpace.App
```

Нужны Windows 10 (2004+) или 11 и .NET 10 SDK.

## Сборка готового приложения

Два варианта одного файла:

```
cd LightSpace

# Маленький exe — нужен установленный .NET 10 Desktop Runtime
dotnet publish LightSpace.App -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish/small

# Самодостаточный exe — .NET внутри, сжат; запускается на любом Windows 10 (2004+) / 11 x64
dotnet publish LightSpace.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish/full
```

Отладочная информация в Release встроена в exe (`DebugType=embedded` в `Directory.Build.props`): отдельных `.pdb` рядом нет, а в журнале ошибок есть номера строк.

## Релиз

Версия задаётся в `LightSpace.App/LightSpace.App.csproj` (`<Version>`) и видна в «Настройках» → «О приложении». Релиз собирается сам: достаточно отправить тег

```
git tag v1.0.0
git push origin v1.0.0
```

GitHub Actions (`.github/workflows/release.yml`) прогонит тесты, соберёт оба варианта exe с версией из тега и выложит их на страницу релиза. Приложение при запуске проверяет последний релиз на GitHub и, если он новее, показывает наверху «Настроек» плашку с кнопкой «Скачать».

## Особенности по типам лент

- **Bluetooth**: лента не должна быть подключена к телефону — пока к ней подключено приложение, она не видна при поиске.
- **Govee**: в приложении Govee Home включите *LAN Control* в настройках каждой ленты.
- **Tuya**: устройство найдётся автоматически, но для управления нужен его *Local Key*. Ключ можно получить через `python -m tinytuya wizard` или на iot.tuya.com. Поддерживаются протоколы **3.3**, **3.4** и **3.5** (3.4 и 3.5 при каждом подключении согласуют сессионный ключ; неверный Local Key покажется ошибкой связи).
- **WLED**: ленты на ESP с прошивкой WLED находятся сами (mDNS), кадры идут по DDP. Без кадров WLED через пару секунд возвращается к своему эффекту.
- **OpenRGB**: запустите OpenRGB и включите в нём *SDK Server* (порт 6742) — каждый его контроллер (плата, память, видеокарта, мышь) станет отдельным устройством. OpenRGB должен быть запущен на этом же компьютере.
- **Robobloq**: перед поиском закройте SyncLight (в том числе в трее), иначе обе программы будут одновременно слать ленте команды.
- **Arduino**: залейте `Arduino/LightSpaceStrip/LightSpaceStrip.ino` (библиотека FastLED), задайте уникальное `DEVICE_NAME`, пин и число светодиодов. При поиске программа шлёт `PING` во все COM-порты и ждёт ответа `LIGHTSPACE <имя>`.
