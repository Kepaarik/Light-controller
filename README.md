# LedHub

Десктопное приложение (WPF, .NET 10) для управления несколькими светодиодными лентами из одного окна.

## Что умеет

- **Автопоиск** сразу при запуске и по кнопке — одновременно по всем типам подключения (≈8–15 секунд):
  | Тип | Как ищется | Как управляется |
  |---|---|---|
  | Bluetooth LE: ELK-BLEDOM / MELK (duoCo Strip, Lotus Lantern) | рекламные пакеты BLE, затем проверка GATT-сервиса `FFF0` | запись в характеристику `FFF3` |
  | Bluetooth LE: Triones / LEDBLE (Happy Lighting) | то же, сервис `FFD5` | запись в `FFD9` |
  | Wi-Fi Magic Home | UDP-broadcast `HF-A11ASSISTHREAD` на порт 48899 | TCP 5577 |
  | Wi-Fi Govee | multicast `239.255.255.250:4001` | UDP 4003 (LAN API) |
  | Wi-Fi Tuya / Smart Life | прослушивание анонсов на UDP 6666/6667 | TCP 6668, протокол 3.3 |
  | Arduino по USB | опрос всех COM-портов командой `PING` | текстовые команды по Serial |
  | Подсветка монитора Robobloq (SyncLight) | USB HID `1A86:FE07`, запрос параметров ленты | HID-отчёты по протоколу из драйвера OpenRGB |
- **Группы**: отметьте ленты галочками → «Создать из отмеченных». Команды группе уходят на все её ленты одновременно. Группы сохраняются в `%AppData%\LedHub\config.json` и переживают перезапуск; участники, которых сейчас не нашлось, показываются как «не найдено».
- **Управление**: вкл/выкл (в том числе кнопкой прямо в списке слева), цвет (цветовой круг, быстрые цвета, точная настройка RGB), яркость.
- **Эффекты приложения**: радуга, смена цветов, дыхание, волна, комета, звёзды, огонь, полиция, стробоскоп, свеча. Их рассчитывает приложение, поэтому они работают на любых лентах и синхронно во всей группе, пока LedHub открыт.
- **Эффекты контроллера**: встроенные эффекты Robobloq и MELK-OA21/OA10/OC10/OF10 (у MELK-OA21 — более двухсот: огонь, потоки, занавес, переливы…). Работают и при закрытом приложении. Команды MELK взяты из интеграции [elkbledom](https://github.com/dave-code-ruiz/elkbledom) для Home Assistant.
- **Музыка с компьютера** (вкладка «Музыка»): ленты реагируют на звук, который играет в колонках или наушниках (перехват WASAPI через NAudio, микрофон не нужен). Режимы «Пульс», «Спектр», «Радуга по битам», автоусиление и чувствительность. Адресные ленты показывают шкалу громкости или полосы спектра по светодиодам.
- **Подсветка под экран** (вкладка «Экран»): ленты 20 раз в секунду повторяют цвета основного монитора. Обычные — средний цвет картинки, адресные за монитором — цвета краёв экрана. Для каждой адресной ленты настраивается расположение: какие стороны заняты, угол начала, направление, число светодиодов на каждой стороне и сдвиг — со схемой монитора.
- **Микрофон контроллера** (MELK-OA21, вкладка «Музыка»): включение и выключение встроенного микрофона, 8 музыкальных режимов и чувствительность — лента сама реагирует на звук рядом с ней.
- **Сцены** (боковая панель): текущее состояние всех лент — включение, цвет, яркость — сохраняется под именем и включается одним кликом.
- **Таймер сна** (кнопка с часами в шапке): выключить ленту или группу через 15, 30, 60 или 120 минут, с обратным отсчётом. Работает, пока LedHub открыт.
- **Недавние цвета**: последние 10 выбранных цветов на вкладке «Цвет».
- **Названия**: ленте или группе можно дать своё имя на вкладке «Настройки».
- **Форма из шестигранников** (вкладка «Форма», только для адресных лент): выложите шестигранники на сетке так же, как они висят на стене, и рисуйте по 7 светодиодам каждого. Форма и рисунок сохраняются и сразу отправляются на ленту. У MELK-OA21 вкладки нет: его контроллер не принимает цвета отдельных светодиодов (проверено, в том числе командой штор-матриц из Lotus Lamp X).
- **Отдельные светодиоды**: у адресных лент (Robobloq, Arduino с WS2812) каждый светодиод можно закрасить своим цветом. Обычные RGB-ленты светятся одним цветом целиком, для них это невозможно физически.

## Запуск

```
cd LedHub
dotnet run
```

Нужны Windows 10 (2004+) или 11 и .NET 10 SDK.

## Особенности по типам лент

- **Bluetooth**: лента не должна быть подключена к телефону — пока к ней подключено приложение, она не видна при поиске.
- **Govee**: в приложении Govee Home включите *LAN Control* в настройках каждой ленты.
- **Tuya**: устройство найдётся автоматически, но для управления нужен его *Local Key* (выберите ленту → «Настройки Tuya»). Ключ можно получить через `python -m tinytuya wizard` или на iot.tuya.com. Поддерживается протокол **3.3**; устройства 3.4/3.5 будут найдены, но помечены как неподдерживаемые.
- **Robobloq**: перед поиском закройте SyncLight (в том числе в трее), иначе обе программы будут одновременно слать ленте команды.
- **Arduino**: залейте `Arduino/LedHubStrip/LedHubStrip.ino` (библиотека FastLED), задайте уникальное `DEVICE_NAME`, пин и число светодиодов. При поиске программа шлёт `PING` во все COM-порты.
- Контроллеры не сообщают своё текущее состояние, поэтому панель показывает последний цвет, выставленный из LedHub.
