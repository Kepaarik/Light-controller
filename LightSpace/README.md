# Light Space

Новая версия LedHub: одно приложение в трее, которое управляет подсветкой всех лент и клавиатур и продолжает работать при свёрнутом окне.

Старый LedHub лежит рядом, в папке `LedHub`, и остаётся рабочим, пока Light Space не заменит его полностью.

## Проекты

| Проект | Что в нём |
| --- | --- |
| `LightSpace.Core` | Цвета, геометрия сцены, модели конфигурации |
| `LightSpace.Devices` | Драйверы устройств |
| `LightSpace.Engine` | Цикл кадров, рендер содержимого, вывод на устройства, источники (экран, звук, игры), импорт из LedHub |
| `LightSpace.App` | Окно, трей, страницы и компоненты дизайн-системы |

## Что умеет сейчас

- **Окно** на тёмном стекле, как в LedHub (Acrylic или Mica, пресеты и ползунки тонировки). Левое меню сворачивается до значков: «Устройства», «Мониторы», список найденных устройств и внизу «Настройки».
- **Устройства**: поиск по Bluetooth, Wi-Fi и USB (ELK/MELK и Triones, Magic Home, Govee, Tuya, Arduino, Robobloq, Royal Kludge S98), «Забыть», локальный ключ Tuya, возможности устройства и диагностика вывода (отправлено, пропущено кадров, последняя ошибка, время расчёта кадра).
- **Страница устройства** (пункт устройства в меню): своё содержимое и яркость у каждого устройства. Доступны типы «Эффект» (галерея эффектов с настройками), «Музыка» (спектр, ритм, пульс от звука компьютера) и «Встроенный» (эффекты контроллера с вариантами — только у устройств, где они есть). Просмотр другого типа не останавливает то, что играет, пока не нажата «Включить». У ленты можно выбрать монитор, за которым она висит.
- **Мониторы**: лента за монитором, ориентация монитора, раскладка ленты по сторонам, начало и направление.
- **Настройки**: стекло, общий выключатель подсветки, автозапуск с Windows (старт сразу в трей), импорт из LedHub.
- **Трей**: своё меню «Открыть Light Space» / «Выход». Свернуть — окно прячется в трей, подсветка работает; закрыть — приложение завершается.
- Настройки — в `%AppData%\LightSpace\config.json` (формат версии 4).

Пока не показываются: страница «Сцена» (режимы «Вся сцена» и «Группы», расстановка, слои) и типы «Сцена», «Экран», «Игра» — код для них есть, но в интерфейсе они выключены, а устройства, которые их играли, при запуске переходят на обычный эффект.

## Запуск

```
cd LightSpace
dotnet run --project LightSpace.App
```

Нужны Windows 10 (2004+) или 11 и .NET 10 SDK.
